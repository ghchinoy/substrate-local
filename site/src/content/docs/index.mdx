## Why `substrate-local`?

<CardGrid>
  <Card title="~3s Zero-Docker Boot" icon="rocket">
    Start PostgreSQL, <code>substrate-local</code>, and unmodified upstream <code>ax-server</code> in seconds—without Docker Desktop, Colima, or a 6–8 GiB Kind VM.
  </Card>
  <Card title="Apple container & Rootless Podman" icon="laptop">
    Runs natively on macOS <code>Virtualization.framework</code> microVMs and default rootless Podman on macOS & Linux, including dual-cluster cross-runtime mobility.
  </Card>
  <Card title="OCI Runner Image Volumes" icon="puzzle">
    Pulls and caches read-only <code>ActorTemplate</code> OCI image volumes (<code>--runner-volume-image</code> at <code>/opt/ax</code>) so plain language images and prebuilt agents run unmodified.
  </Card>
  <Card title="Embeddable Go pkg/sublocal" icon="seti:go">
    Zero dependency on <code>github.com/google/ax</code>—only <code>go.ate.dev/substrate v1.0.1</code>, gRPC, Protobuf, and YAML. Guarded by automated <code>ControlServer</code> RPC coverage tests.
  </Card>
</CardGrid>

## Start in 60 seconds

```bash
git clone https://github.com/ghchinoy/substrate-local.git
cd substrate-local
make up                                 # Apple container (or: AX_LOCAL_RUNTIME=podman make up)
source .substrate-local/env

ax apply -f examples/task-local.yaml
ax resume task local-task
ax ssh local-task -- uname -sm          # Linux aarch64
```
